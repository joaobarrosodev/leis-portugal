# Autorização da CNPD n.º 1058/2004

COMISSAO NACIONAL
DE PROTECÇAO DE DADOS
Proc. 490/03 e 1409/2004
AUTORIZAÇÃO N.° 1058 /2004
A Companhia IBM Portuguesa, SA veio notificar à Comissão Nacional de Protecção de Dados (CNPD) dois tratamentos de dados com a seguinte finalidade:
a) Controlo internacional, de forma centralizada, de várias rubricas de remuneração de empregados";
b) "Processamento de salários e gestão administrativa dos empregados", permitindo, ainda, a gestão de informação para "subscrição de acções".
No âmbito do cumprimento destas finalidades, os dados são transferidos para os EUA.
A IBM propõe-se obter o consentimento dos trabalhadores para fundamentar o fluxo de dados para os EUA.
Verifica-se que a IBM tem formulário no qual solicita o consentimento expresso dos trabalhadores para fazer fluxo de dados para os EUA no âmbito de um «plano de aquisição de acções IBM Corporation para empregados» (cf. Proc. 488/2003).
As categorias de dados tratados são necessários e não excessivos em relação à finalidade (cf. art. 5.° da Lei 67/98, de 26 de Outubro).
Nos termos do disposto no artigo 20.º e na alínea e) do n.º 1 do artigo 23.° da Lei de
Protecção de Dados Pessoais, a transferência de dados pessoais para países terceiros carece de autorização da CNPD.
Nos termos do artigo 20.º da Lei 67/98, de 26 de Outubro, a transferência de dados pessoais para os EUA pode ser permitida pela CNPD se o titular dos dados tiver nela consentido inequivocamente. A IBM propõe-se obter esse consentimento.
No entanto, as declarações juntas aos vários processos apenas obtêm o consentimento no âmbito de um «plano de aquisição de acções». Por isso, os impressos devem ser adaptados às finalidades de cada um dos tratamentos.

DE PROTECÇAO DE DADOS 3. A CNPD admite que a transferência de dados se apresente como uma razão de interesse para o titular dos dados.
Face a todo o exposto DELIBERA esta CNPD, nos termos do disposto no n.º 1 do artigo 20.º da Lei n.° 67/98, de 26 de Outubro, autorizar o tratamento de dados pessoais, bem como a sua transmissão para os EUA. A entidade responsável deve cumprir as exigências relativas ao direito de informação e consentimento informado.

# Autorização da CNPD n.º 1057/2004

COMISSÃO NACIONAL
DE PROTECÇAO DE DADOS
Ртос. 488/03
AUTORIZAÇÃO N.°| 057/2004
A Companhia IBM Portuguesa, SA veio notificar à Comissão Nacional de Protecção de Dados (CNPD) o tratamento de dados destinado a permitir ocontrolo internacional, de forma centralizada, de todos os movimentos de empregados de entrada, saída, transferência entre departamentos e/ou países". Para assegurar este controlo os dados são transferidos para Espanha e para os EUA.
A IBM propõe-se obter o consentimento dos trabalhadores para fundamentar o fluxo de dados para os EUA.
1. As categorias de dados tratados (acima indicados) são necessários e não excessivos em relação à finalidade (cf. art. 5.° da Lei 67/98, de 26 de Outubro).
2. Nos termos do disposto no artigo 20.º e na alínea e) do n.º 1 do artigo 23.° da Lei de
Protecção de Dados Pessoais, a transferência de dados pessoais para países terceiros carece de autorização da CNPD.
Nos termos do artigo 20.º da Lei 67/98, de 26 de Outubro, a transferência de dados pessoais para os EUA pode ser permitida pela CNPD se o titular dos dados tiver nela consentido inequivocamente. A IBM propõe-se obter esse consentimento.
No entanto, do teor da declaração verifica-se que o consentimento é dado no âmbito de um «plano de aquisição de acções». Por isso, o impresso deve ser adaptado à finalidade do presente tratamento.
3. A CNPD admite que a transferência de dados se apresente como uma razão de interesse para o titular dos dados.
Face a todo o exposto DELIBERA esta CNPD, nos termos do disposto no n.º 1 do artigo 20.° da Lei n.º 67/98, de 26 de Outubro, autorizar o tratamento de dados pessoais,

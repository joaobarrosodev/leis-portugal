# Autorização da CNPD n.º 4640/2010

COMISSÃO NACIONAL
DE PROTECÇAO DE DADOS
Processo n° 8223/2010
AUTORIZAÇÃON 4640/2010 1 - Franquiger - Gestão de Franquias, S.A., veio solicitar à Comissão Nacional de
Protecção de Dados (CNPD) autorização para comunicar à empresa Cardmobili
Desenvolvimento de Software, S.A., dados pessoais dos seus clientes para efeitos de emissão do cartão Club LDC Seven Plus.
Os dados objecto de registo são os seguintes:
Nome, data de nascimento, e-mail, número de telefone, morada.
Como fundamento da legitimidade do tratamento o requerente invoca a execução de obrigação contratual.
A recolha de dados é feita de forma directa, pessoalmente, por via telefónica, internet ou por impresso, sendo os dados actualizados pela mesma forma.
A segurança é garantida por cópias de backup, password de acesso às informações, sistema de processamento de backup e acesso restrito das pessoas às instalações.
Pretende-se que os dados sejam conservados enquanto o titular dos dados for cliente da requerente.
2 - Os dados pessoais têm que ser recolhidos para finalidades determinadas, explicitas e legitimas e devem ser adequados, pertinentes e não excessivos (cf. artigo 5° nº1, alíneas b) e c), da Lei n° 67/98, 26.10), sendo que qualquer outra utilização desses dados

COMISSAO NACIONAL
DE PROTECÇAO DE DADOS pessoais para fins não determinantes dessa recolha carece do controle prévio da CNPD (cf. artigo 28° n° 1, alínea d) do mesmo diploma).
No caso em apreço, os dados são tratados no âmbito de uma relação contratual, com consentimento dos respectivos titulares. A fonte de legitimidade assenta assim no consentimento, pelo que a Comissão Nacional de Protecção de Dados considera existir legitimidade para o tratamento dos dados que o requerente se propõe realizar (cf. artigos 3°, alínea h), e 6° (corpo) da Lei n° 67/98, de 26.10).
A informação tratada é recolhida de forma lícita (artigo 5°, n.º1 alínea a) da Lei n° 67/98), para finalidades determinadas, explícitas e legítimas (cf. alínea b) do mesmo artigo) e a informação recolhida não é excessiva.
Afiguram-se ajustadas as medidas de segurança adoptadas para impedir o acesso à informação a pessoas não autorizadas. Todavia, independentemente das medidas tomadas é o responsável pelo tratamento que está obrigado a garantir sempre a segurança da informação.
Considera-se ajustado o prazo proposto para a conservação dos dados.
3 - Nestes termos, ao abrigo do disposto nos artigos 23° n° 1, alínea c) e 28° n° 1, alínea d) da Lei n° 67/98, de 26.10, a Comissão Nacional de Protecção de Dados (CNPD)
autoriza o tratamento de dados pessoais supra apreciado, consignando-se o seguinte:
Responsável pelo tratamento: Franquiger - Gestão de Franquias, S.A.
Finalidade do tratamento: emissão do cartão Club LDC Seven Plus
Categorias de dados pessoais tratados: Nome, data de nascimento, e-mail, número de telefone, morada

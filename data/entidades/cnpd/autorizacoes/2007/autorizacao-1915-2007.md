# Autorização da CNPD n.º 1915/2007

COMISSAO NACIONAL
DE PROTECÇAO DE DADOS
Processo n° 3983/06
AUTORIZAÇÃO N° 1915/07 1 - A UNIDADE LOCAL DE SAÚDE DO NORTE ALENTEJANO veio solicitar à
Comissão Nacional de Protecção de Dados autorização para efectuar tratamentos de dados pessoais com a finalidade de gestão de informação relativa à actividade Logística,
Farmacêutica e de Prescrição médica.
Os tratamentos de dados ora notificados decorrem da instalação do software Ges-Log (Logística hospitalar), Ges-Farm (Farmácia) e Ges-Pres (Prescrição médica on-line), que no seu conjunto constituem o SGICM - Sistema de Gestão Integrada do Circuito do
Medicamento -, permitindo uma solução única e integrada para a gestão dos serviços de aprovisionamento e farmácia dos Hospitais, integrada com a prescrição médica hospitalar.
Declara as seguintes categorias de dados pessoais: nome do doente, cama, médico responsável, diagnóstico, reacções alérgicas, artigos de consumo clínico, medicamentos prescritos pelo médico.
Os dados de prescrição são recolhidos directamente pelo médico. No software SGICM ficam registados os medicamentos prescritos a cada doente. Apenas o médico tem acesso a esta função.
Há comunicação de dados ao IGIF, para conferência de facturas.

As medidas de segurança adoptadas são as seguintes: cópias de backup, password de acesso às informações, acesso restrito de pessoas, sistemas de alarme e resposta.

A identificação única de cada utilizador, bem como a data e hora, fica associada a cada registo efectuado. A comunicação de dados pessoais é cifrada.

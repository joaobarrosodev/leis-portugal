# Autorização da CNPD n.º 116/1997

INFORMATIZADOS
O programa tem duas partes distintas : uma respeitante a dados de identificação pessoal, de carácter administrativo, outra contendo informações médicas relativas ao doente. Inclui-se a possibilidade de recolha de informação existente no Cartão Vital, se tal for disponibilizado e autorizado pelo seu titular. O acesso aos dados constantes deste Cartão depende da sua inserção num leitor apropriado, da identificação do titular do cartão pelo seu código secreto de acesso (PIN), primeiro para a informação geral, e, se necessário, por um segundo código de acesso a informação classificada como confidencial.
O acesso à base de dados é direito exclusivo do médico, titular da licença de utilização do Programa, sendo assegurado através de um cartão com microship incorporado, também contendo um código pessoal, fornecido ao médico e exemplar único.O programa desliga-se automaticamente, caso o cartão não seja introduzido em cada 30 minutos( considerado o tempo médio de uma consulta).
A formatação do programa e as seguranças implementadas asseguram a separação lógica dos dados administrativos, que poderão ser acedidos por pessoal administrativo, dos dados de natureza médica, apenas acessíveis a médicos, nos termos acima descritos. Os dados médicos registados pelo médico ou provenientes do cartão vital são sempre encriptados.

INFORMATIZADOS 4. Fundamento da recolha de dados:
Consentimento expresso dos titulares.
5. Recolha directa : com base na consulta e em exames e análises clínicas objectivas.
6. Recolha Indirecta: com base nos dados inseridos no Cartão Vital, desde que autorizado pelo titular, com base no cartão cedido voluntariamente, e cujo acesso tem de autorizar através do código pessoal (PIN).
7. Forma de actualização dos dados: pessoalmente, no momento da consulta.
8. Os dados de identificação podem ser comunicados para fins administrativos.
9. Há relacionamento da informação tratada, entre os dados inseridos pelo médico e os dados recolhidos no cartão.
10. Não há fluxos transfronteiras de dados.
11. Medidas de segurança : palavra-chave de acesso às informações e acesso restrito de pessoas. O responsável da base dados( médico) é o único autorizado a aceder-lhes( dados clínicos). Os dados são encriptados no registo.Há separação lógica dos dados administrativos e clínicos. Os dados de identificação podem ser acedidos por pessoal administrativo.
Acesso aos dados por cartão, com tempo definido para a sua nova inserção( 30 minutos).
12. Tempo de conservação: Os dados de natureza clínica devem ser conservados, de acordo com a relação existente entre o médico e o paciente e o grau de intervenção pontual, continuada ou irregular dos actos médicos.

# Autorização da CNPD n.º 5003/2012

COMISSÃO NACIONAL
DE PROTECÇAO DE DADOS
Processo n.° 16956/2011
AUTORIZAÇÃON.° 5003 12012
L.
Do Pedido
A University Hospital Freiburg notificou à CNPD um tratamento de dados pessoais com a finalidade de elaborar um estudo observacional sobre as imunodeficiências primárias.
O estudo insere-se no Projecto ESID (Sociedade Europeia de Imunodeficiências Primárias)
on-line Patient and Reseach - Registry/Database", estando a base de dados on-line centralizada no Hospital Universitário de Freiburg (Alemanha).
O registo on-line disponibiliza duas versões da base de dados:
1. Base de dados codificada, cuja chave apenas é do conhecimento do médico assistente, que contém o código do participante, ano de nascimento, sexo, peso, altura, perímetro da cabeça, país de residência, consanguinidade, gémeos, mutações genéticas, história médica, resultados clínicos e laboratoriais, medicação, hábitos tabágicos e neurodegeneração;
2. Base de dados nominativa, da qual consta a informação médica dos participantes no estudo, mas também o seu nome, morada, data de nascimento, nome e morada do médico. Neste caso, os dados identificáveis são armazenados num servidor diferente daquele que guarda a informação médica. Um terceiro servidor permite estabelecer a ligação entre os dois servidores, mediante a inserção do nome de utilizador, palavra passe e nome do centro.
Apenas os utilizadores de cada centro participante do registo em que o doente é tratado terão acesso aos dados dos respectivos pacientes. No entanto, será possível obter permissão para aceder aos dados dos pacientes de outros centros, desde que codificados.
A responsável pelo tratamento pretende ainda que os mesmos dados codificados sejam transmitidos a várias companhias farmacêuticas, que patrocinam o projecto.
Serão incluídos no estudo os doentes com imunodeficiências primárias, diagnosticados num dos centros participantes do estudo.

O médico assistente, investigador no estudo, solicitará consentimento informado, cuja declaração será arquivada no processo clínico.
Os dados serão recolhidos num caderno de recolha de dados em suporte eletrónico.
Caso os participantes também o consintam, os dados sobre as alterações genéticas que condicionam a sua imunodeficiência primária serão comunicados e conservados pelo Instituto
Médico e Tecnológico da Universidade de Tampere (Finlândia).
IL.
Da Análise
Analisado o processo, foi proferido o Projecto de Autorização n.º 85/2012, de 07 de Maio que não autorizava a transmissão de dados nominativos dos participantes no estudo para a base de dados on-line, nem a comunicação de dados codificados. No mesmo Projecto, alertava-se para a necessidade de ser reformulado o texto da declaração de consentimento, por forma a serem corrigidos os pontos assinalados, enquadrando-se o tratamento com os princípios norteadores da proteção de dados pessoais.
Notificada para exercer o direito de audição que lhe assiste, nos termos do artigo 100° do CPA, a responsável pelo tratamento de dados não se pronunciou, pelo que se vem converter em
Autorização o Projecto supra referido.
Uma vez que não se vislumbra a necessidade de transmissão de dados nominativos para a base de dados on-line, e que essa transmissão se considera excessiva à luz dos principios da protecção de dados pessoais, apenas se autoriza a criação da base de dados codificada, ficando a chave da codificação apenas na posse do médico assistente.
A CNPD já se pronunciou na sua Deliberação n.º 227/2007 sobre o enquadramento legal, os fundamentos de legitimidade, os principios orientadores para o correcto cumprimento da Lei de
Protecção de Dados, bem como as condições gerais aplicáveis ao tratamento de dados pessoais para esta finalidade.
No caso em apreço, a notificação enquadra-se no âmbito tipificado por aquela Deliberação.

COMISSÃO NACIONAL
DE PROTECÇAO DE DADOS
A informação tratada é recolhida de forma lícita (art.° 5°, n.º1 al. a) da Lei 67/98), para finalidades determinadas, explícitas e legítimas (cf. al. b) do mesmo artigo) e não é excessiva, salvo a transmissão de dados nominativos para a base de dados on-line.
Assim, apenas o registo de dados codificado se encontra de acordo com os princípios orientadores da proteção de dados pessoais.
Por outro lado, às companhias farmacêuticas apenas poderão ser comunicados dados anonimizados.
O fundamento de legitimidade é o consentimento expresso do titular dos dados. Quando houver recolha de dados de menores, terá de ser prestado o consentimento pelos legais representantes. Impõe-se, ainda, que a criança seja ouvida e em função da idade, nos termos da lei, ela própria preste a sua anuência à recolha de dados pessoais para participação no estudo. O estudo deve ter em conta o superior interesse da criança.
Não se autoriza a transmissão de dados nominativos dos participantes no estudo para a base de dados on-line, nem a comunicação de dados codificados. O texto da declaração de consentimento terá de ser reformulado, por forma a serem corrigidos os pontos assinalados, enquadrando-se o tratamento com os princípios norteadores da proteção de dados pessoais
Da Conclusão
Assim, nos termos das disposições conjugadas do n.º 2 do artigo 7.°, n.º1 do artigo 27°, al. a)
do n.º 1 do artigo 28° e art. 30° da Lei de Protecção de Dados, com as condições e limites fixados na referida Deliberação n.º 227/2007, que se dão aqui por reproduzidos e que fundamentam esta decisão, e ainda com as condições aqui fixadas, autoriza-se o tratamento de dados supra referido, para a elaboração do presente estudo.

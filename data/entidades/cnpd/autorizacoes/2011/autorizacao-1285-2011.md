# Autorização da CNPD n.º 1285/2011

COMISSAO NACIONAL
DE PROTECÇAO DE DADOS
Processo n° 3867/2006
AUTORIZAÇÃO N° / 285/20M 1 - Estoril Sol (III) - Turismo Animação e Jogo, S.A., veio notificar à Comissão
Nacional de Protecção de Dados (CNPD) um tratamento de dados pessoais com a finalidade de gestão de clientes e marketing.
Os dados objecto de registo são os seguintes:
Nome, morada, número de telefone, profissão, data de nascimento, data de casamento e histórico de utilização do cartão Clube In.
Como fundamento da legitimidade do tratamento a requerente invoca o consentimento dos titulares dos dados e a prossecução de interesse legítimo.
Os dados são recolhidos com o consentimento do titular, conforme modelo junto aos autos, sendo a recolha feita de forma directa, pessoalmente, ou indirectamente, sempre que o cliente introduz o cartão Clube In nas máquinas de jogos, sendo os dados actualizados pela mesma forma.
A segurança é garantida por password de acesso às informações e acesso restrito das pessoas às instalações.
Pretende-se que os dados sejam conservados enquanto a relação contratual se mantiver.
2 - Para além de dados de identificação e de contacto, pretende a requerente tratar informações sobre hábitos dos seus clientes, as quais manifestamente dizem respeito à "vida privada", nos termos definidos no artigo 7° n°s 1 e 2 da Lei n° 67/98.

COMISSÃO NACIONAL
DE PROTECÇÃO DE DADOS
O tratamento de dados para determinação do perfil de cliente não pode ser efectuado sem o consentimento expresso do titular dos dados.
Uma vez que o modelo de formulário de recolha de dados junto aos autos apenas respeita aos dados necessários ao registo do cliente, deverá a requerente adoptar um texto em que se informe o titular que o tratamento abrange a determinação do seu perfil no qual aquele seja interpelado a expressar de forma inequívoca o consentimento ao tratamento com essa finalidade.
Aquele modelo é também omisso no que se refere ao direito dos titulares de manifestarem oposição a que os seus dados sejam utilizados para efeitos de marketing pelo responsável pelo tratamento ou por terceiros a quem este os comunique com tal objectivo (artigo 12°, alínea b) da Lei n° 67/98). Importa por isso fazer consignar que o titular dos dados tem legitimidade para se opor à realização de acções de marketing, devendo o impresso de recolha de dados estar preparado para consignar esse direito de oposição.
Quanto aos restantes dados, sendo os mesmos tratados no âmbito de uma relação contratual, com consentimento expresso do titular, a CNPD considera que existe legitimidade para o tratamento (cf. artigo 6°, alínea a), da Lei n° 67/98, de 26.10).
A informação tratada é recolhida de forma lícita (artigo 5°, n.º1 alínea a) da Lei n° 67/98), para finalidades determinadas, explícitas e legítimas (cf. alínea b) do mesmo artigo) e a informação recolhida não é excessiva.
Afiguram-se ajustadas as medidas de segurança adoptadas para impedir o acesso à informação a pessoas não autorizadas. Todavia, independentemente das medidas tomadas é o responsável pelo tratamento que está obrigado a garantir sempre a segurança da informação.
Considera-se ajustado o prazo proposto para a conservação dos dados.

# Autorização da CNPD n.º 461/2006

COMISSÃO NACIONAL
DE PROTECÇAO DE DADOS
Proc.° n° 478/02 461
AUTORIZAÇÃO N°
/ 2006
O BBVA - Sociedade de Locação Financeira, SA, veio requerer autorização para tratamento de dados pessoais dos seus clientes para a finalidade de análise de risco, celebração e execução de contratos de locação financeira.
Do requerimento apresentado pela empresa, resulta que é solicitada autorização, ao abrigo da al. b) do n° 1 do art° 28° da LPD (Lei da Protecção de Dados - Lei n° 67 / 98 de 26 de Outubro), para proceder ao tratamento de dados pessoais relativos ao crédito e à solvabilidade dos titulares.
Do pedido de autorização verifica-se que:
a) Dos modelos anexos e do pedido formulado, conclui-se que a requerente pretende tratar os dados seguintes: identidade; residência; contacto; sexo; estado civil; situação familiar; situação profissional; salário; encargos mensais com a habitação; habilitações literárias; os mesmos dados pessoais do cônjuge, se casado.
b) A finalidade do tratamento é a criação do registo para assistência a contratos de financiamento e concessão de crédito.
c) Os dados são recolhidos directamente.
d) A actualização dos dados é feita directamente.
e) Pretende a requerente autorização para que os dados sejam comunicados para efeitos de cobrança de créditos incumpridos.
f) A segurança das informações é garantida através de cópias de backup, password de acesso às informações, restrição de acesso físico de pessoas e sistemas de alarme e resposta.

DE PROTECÇAO DE DADOS g) A requerente pretende conservar os dados pessoais recolhidos por tempo indeterminado.
h) A entidade requerente assegura aos titulares dos dados o direito de correcção das informações, de forma imediata desde que solicitada pelos titulares.
Da pretensão da requerente acima exposta e da análise dos elementos que mais e maiores cuidados reclamam, importa abordar, do ponto de vista jurídico e à luz da LPD, as questões seguintes:
1) Os dados tratados, atenta a finalidade do tratamento, são adequados, pertinentes e não excessivos.
2) A requerente encontra o fundamento de legitimidade para proceder ao tratamento dos dados pessoais dos titulares no consentimento prestado por estes.
O consentimento é uma manifestação de vontade livre, específica (expressa) e informada através da qual o titular aceita o tratamento dos seus dados pessoais.
Por conseguinte, deverá ser estritamente cumprido o dever de informação consignado no artigo 10° da LPD.
Impende sobre a entidade responsável pelo tratamento aqui requerido a obrigação de proceder e de manter os dados exactos e actualizados, sempre com observância do princípio da boa fé.
Uma vez que o BBVA pretende comunicar as situações de incumprimento (informação negativa) a outras instituições, deve ser prevista a inclusão de espaço consignado para a informação, ponto de vista e posição tomada pelos titulares sobre o tratamento dos seus dados pela entidade requerente.

CallCenter.
3) O prazo de conservação dos dados deve limitar-se ao período de vigência do contrato, findo o qual os dados devem ser destruídos das bases do BBVA.
4) Do pedido de autorização trazido pelo BBVA não existem elementos suficientes parta avaliar o preenchimento dos requisitos necessários à interconexão de dados pessoais: não se refere o tipo de dados objecto da interconexão nem se conhecem os responsáveis pelos outros tratamentos sobre os dados pessoais objecto da interconexão, não se especificam as medidas de segurança nem se pode avaliar o risco de discriminação ou a eventual diminuição dos direitos, liberdades e garantias dos titulares dos dados.
5) Recolhendo e tratando o BBVA dados pessoais dos cônjuges dos contraentes, deve o mesmo BBVA obter o consentimento informado destes cônjuges para o tratamento dos seus dados pessoais, de igual modo como obtém dos contraentes principais.
Pelo exposto e concluindo, face ao requerimento apresentado, a CNPD autoriza o tratamento de dados pela requerente nos termos seguintes:
- Responsável: BBVA - SOCIEDADE DE LOCAÇÃO FINANCEIRA SA,
- Finalidade do tratamento: análise de risco, celebração e execução de contratos de locação financeira.
- Categorias dos dados pessoais tratados: identidade; residência; contacto; sexo;
estado civil; situação familiar; situação profissional; salário; encargos mensais com a habitação; habilitações literárias; os mesmos dados pessoais do cônjuge, se casado.

- Cabe à entidade responsável pelo presente tratamento cumprir efectivamente o dever de manter os dados tratados exactos e actualizados.
- Deve a entidade responsável assegurar aos titulares o direito de informação previsto no art° 10°, prestado no momento da introdução dos dados nos seus registos, dando a conhecer aos titulares, entre outros elementos, os destinatários das comunicações, bem como deve ser respeitado, efectivamente, o direito de acesso previsto no art° 11°, ambos da LPD.
- Deve a entidade responsável recolher o consentimento informado dos contraentes principais e dos cônjuges para tratamento dos seus dados pessoais.

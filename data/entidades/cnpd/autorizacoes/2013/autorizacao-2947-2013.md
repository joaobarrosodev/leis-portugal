# Autorização da CNPD n.º 2947/2013

Proc. N.: 1162/2012 1
COMISSÃO NACIONAL
DE PROTECÇÃO DE DADOS
AUTORIZAÇÃO N.° 2947 12013 1. Do Pedido
A Guidant Europe SA/ NV, a Boston Scientific Company (Bélgica) notificou à CNPD um tratamento de dados pessoais com a finalidade de elaborar um estudo observacional de seguimento clínico pós-comercialização de elétrodos de pacemaker para desfibrilhação Reliance 4-Fronf™.
Serão incluídos no estudo aproximadamente 167 indivíduos, maiores, diagnosticados com insuficiência cardíaca e aos quais seja implantado o pacemaker com fixação ativa Reliance 4-Front nos centros participantes.
A participação no estudo consiste na recolha de informações de saúde do processo clínico pelo médico assistente e na resposta a questionários pelos participantes durante dois anos.
O médico assistente, investigador no estudo, solicitará consentimento informado, cuja declaração será arquivada no processo clínico.
Os dados serão recolhidos num caderno de recolha de dados em formato eletrónico.
No "caderno de recolha de dados" não há identificação nominal do titular, sendo aposto um código de doente. A chave desta codificação só será conhecida do médico assistente.
Todavia, a responsável pelo tratamento pretende enviar dados nominativos para a casa-mãe nos Estados Unidos da América, justificando a sua necessidade do seguinte modo: "Este estudo é um estudo de seguimento clínico pós-comercialização de elétrodos para desfibrilhação RELIANCE 4-FRONT que tem como objetivo reunir dados para estabelecer a segurança crónica, o desempenho e a efetividade dos elétrodos de pacemaker para desfibrilhação com fixação ativa RELIANCE 4-FRONT™.

Da Análise
Analisado o processo, foi proferido o Projeto de Autorização n.º 109/2013, de 19 de fevereiro, que não autorizava a comunicação dos dados nominativos para nenhuma entidade.
Notificada para exercer o direito de audição que lhe assistia, nos termos do artigo 100.° do CPA, a responsável pelo tratamento de dados não se pronunciou, pelo que vem esta CNPD converter em Autorização o Projeto supra referido.
A CNPD já se pronunciou na sua Deliberação n.º 227/2007 sobre o enquadramento legal, os fundamentos de legitimidade, os princípios orientadores para o correto cumprimento da Lei n.º 67/98, de 26 de outubro (Lei de Proteção de Dados - LPD), bem como as condições gerais aplicáveis ao tratamento de dados pessoais para esta finalidade.
No caso em apreço, a notificação enquadra-se no âmbito tipificado por aquela
Deliberação.

A informação tratada é recolhida de forma lícita (cfr. alínea a) do n.º 1 do artigo 5.° da
LPD), para finalidades determinadas, explícitas e legítimas (cfr. alínea b) do mesmo artigo).
O fundamento de legitimidade é o consentimento expresso do titular dos dados.
A responsável pelo tratamento pretendia enviar os dados nominativos para os EUA, que é um país que não oferece uma proteção de dados adequada.
Todavia, ainda que esse fluxo de dados fosse para um país que oferecesse uma proteção adequada de dados, não pode a responsável pelo tratamento transmitir dados que não possui. Apenas o médico assistente, investigador no estudo, tem acesso à chave de codificação dos dados, não a podendo transmitir à responsável pelo tratamento, nem a qualquer outra entidade, de acordo com o Princípio da
Minimização do Risco e do Princípio da Necessidade.
Uma vez que em causa está um tratamento de dados sensíveis, nos termos do n.° 2 do artigo 7.° da LPD, o fundamento de legitimidade para o mesmo terá de ser uma disposição legal, o interesse público importante ou o consentimento expresso dos titulares dos dados, desde que com garantias de não discriminação e com as medidas de segurança previstas no artigo 15.° da referida lei.
Por um lado, não pode a responsável pelo tratamento garantir que não venha a existir um tratamento discriminatório dos titulares dos dados. Por outro, a finalidade do tratamento de dados é cumprida com o envio dos dados codificados, pelo que, atendendo aos dados em causa, não é legítima a comunicação dos dados nominativos para nenhuma entidade.

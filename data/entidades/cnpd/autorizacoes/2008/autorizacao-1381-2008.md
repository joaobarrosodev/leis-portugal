# Autorização da CNPD n.º 1381/2008

COMISSÃO NACIONAL
DE PROTECÇÃO DE DADOS
Proc 2852/08 1381
AUTORIZAÇÃO n° /2006 1. A sociedade comercial por quotas Boehringer Ingelheim, Lda., veio notificar o tratamento de dados relativo à gestão de investigadores e bolseiros que trabalham para a requerente no âmbito de ensaios clínicos e estudos não intervencionais. A finalidade do tratamento é a "gestão logística e administrativa de estudos de investigação clínica (ensaios clínicos e estudos não intervencionais).
2. O tratamento de dados inclui a recolha de dados de identificação (nome completo, BI, n° de contribuinte, telefone, morada, n° de cédula profissional), dados de contacto (telefone, correio electrónico, telemóvel), especialidade médica, título académico, experiência, percurso como investigador, motivação para a participação no ensaio/estudo, artigos publicados em revistas científicas.
A informação tratada, no âmbito das finalidades acima indicadas, é recolhida de forma lícita (artigo 5.° n.º 1 al. a), para finalidades determinadas, explícitas e legítimas (artigo 5.° n.º 1 al. b) e com o consentimento expresso e informado dos titulares.
Como medidas de segurança o sistema dispõe de «cópias de backup», sistema de processamento de backup, password e acesso restrito de pessoas.
Os dados são comunicaddos para a base de dados central da empresa mãe, sedeada na Alemanha.
O responsável deverá, ainda, assegurar:
• O direito de informação e acesso aos titulares dos dados, nos termos do artigo 10.° e 11.° n.° 5 da lei 67/98);

COMISSAO NACIONAL
DE PROTECÇÃO DE DADOS
• A informação não pode ser utilizada para finalidades diversas das declaradas.
Considera-se legítimo o tratamento, autorizando-se a recolha de dados (artigo 6° e 28, n.º 1, da Lei 67/98) - devendo ser observadas, ainda as seguintes condições:
1. Responsável - Boehringer Ingelheim, Lda.
2. Finalidade - gestão logística e administrativa de estudos de investigação clínica (ensaios clínicos e estudos não intervencionais).
3. Dados recolhidos - dados de identificação (nome completo, Bl, n° de contribuinte, telefone, morada, n° de cédula profissional), dados de contacto (telefone, correio electrónico, telemóvel), especialidade médica, título académico, experiência, percurso como investigador, motivação para a participação no ensaio/estudo, artigos publicados em revistas científicas.
4. Comunicação e interconexão de dados - Os dados são comunicados à base de dados central do grupo a que pertence a
Responsável 5. Direito de acesso - O titular tem direito de acesso e de rectificação dos dados que lhe dizem respeito, de acordo com o artigo 11°. da Lei n° 67/98.
6. Prazo de conservação - Os dados recolhidos são conservados até ao termo da relação contratual entre a Requerente e os respectivos titulares.

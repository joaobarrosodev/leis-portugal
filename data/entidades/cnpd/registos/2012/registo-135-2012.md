# Registo da CNPD n.º 135/2012

COMISSÃO NACIONAL
DE PROTECÇÃO DE DADOS
Proc®/786/04
REGISTO N° /3Í/2012 1) O Pedido
A empresa Benteler - Indústria de Componentes para Automóveis, Ida notifica tratamento de gestão de dados do pessoal e sua comunicação para a empresa mãe, na
Alemanha.
Os dados a tratar são: nome, BI, morada, contatos telefónicos, data de nascimento, habilitações literárias, disponibilidade para trabalhar noutros países.
Como fundamentos de legitimidade apontam-se o consentimento das titulares e a prossecução de interesses legítimos.
Há comunicação de dados para a rede, na Alemanha.
Refere-se a existência de interconexão, mas esta refere-se à comunicação de dados para a casa-mãe.
Não há fluxos transfronteiras.
Como medidas de segurança apontam-se o acesso restrito de pessoas e a utilização de cópias de back-up dos dados, de palavras-chave de acesso aos dados, de sistemas de processamento de back-up e de sistemas de alarme e resposta.
Como prazo de conservação refere-se 1 ano após a cessação da relação laboral, transitando depois os dados para arquivo morto.
O exercício dos direitos de acesso e retificação é feito perante a responsável (sem especificação de modalidade)
2) Registo
Não se tratam dados sensíveis.
A alegada interconexão é, em boa verdade, uma comunicação de dados para a
Alemanha - país da UE.
Dentro da UE vigora o princípio da livre circulação de dados.
Assim, procede-se ao seguinte registo:

# Registo da CNPD n.º 667/2009

COMISSÃO NACIONAL
Proc. n.
DE PROTEÇAO DE DADOS
Registo n. °667/09
ISDF Portugal - Serviços de Distribuição Frigorifica, Lda notificou um tratamento de dados pessoais com a finalidade de gestão de clientes e fornecedores.
Declaram as seguintes categorias de dados pessoais: Dados de identificação, dados de contacto e dados de facturação.
Os dados são recolhidos directamente por impresso, telefone e internet.
Declaram comunicação de dados às (casas mães) em França e Espanha.
Os dados recolhidos são pertinentes, adequados e não excessivos face à finalidade declarada (Cf. al. b)
do art° 5° da Lei 67/98).
O fundamento de legitimidade para o tratamento é, nos termos da alínea e) do artigo 6° da LPD, o interesse do responsável.
Assim, regista-se, nos termos dos artigos 27° n.º 1 e 30° n.º 1 da Lei n.º67/98, de 26 de Outubro, o tratamento, nos seguintes termos:
Responsável - ISDF Portugal - Serviços de Distribuição Frigorifica, Lda.
Categoria de dados pessoais tratados - Dados de identificação, dados de contacto e dados de facturação.
Finalidade - Gestão de clientes e fornecedores.
Forma de exercício do direito de acesso e rectificação - Solicitação pessoal ou escrita ao responsável pelo tratamento
Interconexões - Não há.
Fluxo transfronteiriço de dados - Não há.
Conservação dos Dados - 10 anos.
Comunicação de dados - Há comunicação de dados para a as "casas mães".
Aos titulares dos dados deve ser garantido o direito de informação previsto no artigo 10° da Lei n.º 67/98, de 26 de Outubro, incluindo o nº4, por haver recolha de dados na Internet.
Alerta-se o responsável que o registo efectuado não inclui a finalidade de marketing. Assim, não é autorizada a comunicação de dados a terceiras entidades para essa finalidade.

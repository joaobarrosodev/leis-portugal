# Registo da CNPD n.º 237/2009

COMISSÃO NACIONAL
DE PROTECÇAO DE DADOS
Proc.n.° 7363/08
Registo n.º237709
Farsana Portugal - Comércio e Indústria, S.A., notificou um tratamento de dados pessoais com a finalidade marketing.
Declara as seguintes categorias de dados pessoais: nome, apelido, data de nascimento, sexo, morada, localidade, código postal, telfone, telmóvel, e-mail, no caso de gravidez mês para o qual está previsto o parto, n° de filhos, nome, apelido e data de nascimento do conjuge.
Os dados são recolhidos directamente por internet.
Os dados recolhidos são pertinentes, adequados e não excessivos face à finalidade declarada (Cf. al. b) do art° 5° da Lei 67/98). Com excepção dos dados dos cônjuges, face à finalidade não se admite a recolha dos dados, salvo se se obtiver o consentimento inequívoco do mesmo.
O fundamento de legitimidade para o tratamento é, nos termos da al.e) do art.6° da LPD, o interesse do responsável.
Assim, regista-se, nos termos dos artigos 27° n.º 1 e 30° n.º 1 da Lei n.º67/98, de 26 de
Outubro, o tratamento, nos seguintes termos:
Responsável - Farsana Portugal - Comércio e Indústria, S.A.
Categoria de dados pessoais tratados - nome, apelido, data de nascimento, sexo, morada, localidade, código postal, telfone, telmóvel, e-mail, no caso de gravidez mês para o qual está previsto o parto, n° de filhos, nome, apelido e data de nascimento do cônjuge.
Finalidade - marketing.
Forma de exercício do direito de acesso e rectificação - Por solicitação ao responsável por internet.
Interconexões - Não há.
Comunicação de dados - Há comunicação de dados para o tratamento de marketing.
Fluxo transfronteiriço de dados - Não há.
Prazo máximo de conservação dos dados- 2 anos.
Aos titulares dos dados deve ser garantido o direito de informação previsto no artigo 10° da
LPD, bem como a possibilidade de se opor à utilização dos seus dados para fins de marketing, previsto na al. b) do artigo 12° da LPD.

# Registo da CNPD n.º 479/2009

COMISSÃO NACIONAL
DE PROTECÇAO DE DADOS
Proc.n.° 4014/07
Registo n.º 477/09
Azevedo Neves, Benjamim Mendes, Bessa Monteiro, Cardigos e Associados,
Sociedade de Advogados, R.L. notificou um tratamento de dados pessoais com a finalidade de gestão de processos de recrutamento de colaboradores.
São declarados os processamentos das seguintes categorias de dados pessoais: dados de identificação, dados de contacto, dados académicos e profissionais, dados relativos ao emprego.
Os dados são recolhidos directamente, através de formulário electrónico disponibilizado para o efeito, com recolha de consentimento expresso para o e, bem assim, com informação quanto aos meios de acesso, de alteração, de rectificação e de eliminação existentes.
Os dados recolhidos são pertinentes, adequados e não excessivos face à finalidade declarada (cfr. o disposto na alínea b) do art. 5° da Lei n.° 67/98, de 26 de Outubro).
O fundamento de legitimidade para o tratamento é, nos termos do estabelecido no corpo do artigo 6.° da Lei n.º 67/98, de 26 de Outubro, o consentimento inequívoco do titular, que disponibiliza os dados pessoais por meio de formulário próprio onde existe declaração de consentimento expresso para o efeito, podendo ainda ser evocado como fundamento de legitimidade para o tratamento, concomitantemente, conforme o disposto na alínea a) do artigo 6.°, a execução de diligências prévias à formação do contrato ou declaração da vontade negocial efectuadas a pedido do titular dos dados pessoais.
Assim, regista-se, nos termos dos artigos 27.°, n.º 1 e 30.°, n.º 1 da Lei n.° 67/98, de 26 de Outubro, o tratamento, nos seguintes termos:

COMISSAO NACIONAL
DE PROTECÇÃO DE DADOS
Responsável - Azevedo Neves, Benjamim Mendes, Bessa Monteiro, Cardigos e Associados, Sociedade de Advogados, R.L.
Categoria de dados pessoais tratados - dados de identificação, dados de contacto, dados académicos e profissionais, dados relativos ao emprego.
Finalidade - gestão de processos de recrutamento.
Comunicação de dados - Não há.
Forma de exercício do direito de acesso e rectificação - Por e-mail ou carta dirigida ao responsável pelo tratamento.
Interconexões - Não há.
Fluxo transfronteiriço de dados - Não há
Tempo de conservação dos dados pessoais - Os dados pessoais podem ser conservados pelo período máximo de 2 anos após o último contacto do titular.
Aos titulares dos dados deve ser garantido o direito de informação previsto no artigo 10°.
Não se autoriza o registo de informação subjectiva que seja susceptível de criar discriminação, designadamente dados relativos a hábitos pessoais dos candidatos.

# Registo da CNPD n.º 103/2009

COMISSÃO NACIONAL
DE PROTECÇAO DE DADOS
Proc.n.° 2533/07
Registo n. 10309
Instituto Portuário e dos Transportes, IP notificou um tratamento de dados pessoais com a finalidade registo central dos inscritos maritimos.
Declaram as seguintes categorias de dados pessoais: Dados de identificação, estado civil, filiação, dados de contacto, inscrição marítima, cédula, aptidão física, classificação, categorias e requisitos de acesso, funções a desempenhar, formação, certificados.
Os dados recolhidos são pertinentes, adequados e não excessivos face à finalidade declarada (Cf. al. b) do art° 5° da Lei 67/98).
O fundamento de legitimidade para o tratamento é o cumprimento de obrigação legal, nos termos do corpo do artigo 6° da LPD ( DL 281/2001)
Assim, regista-se, nos termos dos artigos 27° n.º 1 e 30° n.° 1 da Lei n.º67/98, de 26 de
Outubro, o tratamento, nos seguintes termos:
Responsável - Instituto Portuário e dos Transportes, IP
Categoria de dados pessoais tratados - : Dados de identificação, estado civil, filiação, dados de contacto, inscrição marítima, cédula, aptidão física, classificação, categorias e requisitos de acesso, funções a desempenhar, formação, certificados
Finalidade - registo central dos inscritos marítimos
Comunicação de dados - Não há
Forma de exercício do direito de acesso e rectificação - Por solicitação ao responsável;
Interconexões - Não há;
Fluxo transfronteiriço de dados para países 3°s - Não há.
Aos titulares dos dados deve ser garantido o direito de informação de forma a cumprir o artigo 10° da LPD.

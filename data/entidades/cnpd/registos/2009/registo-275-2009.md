# Registo da CNPD n.º 275/2009

COMISSÃO NACIONAL
DE PROTECÇAO DE DADOS
Proc.n.° 3312/07
Registo n.º 2+J 107
Domingos Gomes & Associado Lda., notificou um tratamento de dados pessoais com a finalidade de recrutamento e selecção de pessoal.
Declaram as seguintes categorias de dados pessoais
- Relativas aos candidatos: Dados de identificação (nome, idade, sexo, NIF) dados de contacto (morada, telefone, telemóvel, endereço de e-mail) , dados académicos e profissionais.
Os dados são recolhidos directamente através da internet.
Os dados recolhidos são pertinentes, adequados e não excessivos face à finalidade declarada (Cf. al. b) do art° 5° da Lei 67/98).
O fundamento de legitimidade para o tratamento é, nos termos do corpo do artigo 6° da LPD, a o consentimento dos titulares dos dados.
Assim, regista-se, nos termos dos artigos 27° n.° 1 e 30° n.° 1 da Lei n.º67/98, de 26 de
Outubro, o tratamento, nos seguintes termos:
Responsável - Domingos Gomes & Associado Lda.
Categoria de dados pessoais tratados - Dados de identificação (nome, idade, sexo, NIF)
dados de contacto (morada, telefone, telemóvel, endereço de e-mail), dados académicos e profissionais.
Comunicação de dados - não há
Finalidade - Recrutamento e selecção de pessoal.
Forma de exercicio do direito de acesso e rectificação - Directamente na internet (área reservada do candidato)
Interconexões - Não há;
Fluxo transfronteiriço de dados para paises terceiros - Não há.
Aos titulares dos dados deve ser garantido o direito de informação previsto no artigo 10°, incluindo o n.° 4 uma vez que há recolha de dados em rede aberta.

DE PROTECÇAO DE DADOS
Não se autoriza o tratamento de dados relativos a hábitos, designadamente o consumo de álcool, café ou tabaco, ainda que estes tenham sido fornecidos pelo respectivo titular no currículo. Não se autoriza, também, a recolha de dados de saúde, dados relativos a familia e dados sobre os hábitos pessoais.
As informações recolhidas devem limitar-se às questões que incidam sobre as qualificações e a experiência profissional dos trabalhadores.

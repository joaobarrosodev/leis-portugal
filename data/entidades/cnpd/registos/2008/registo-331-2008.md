# Registo da CNPD n.º 331/2008

COMISSÃO NACIONAL
DE PROTECÇÃO DE DADOS
Processo n.º 688/087
Registo n.°33 1 12008
A Intercampus- Recolha, Tratamento e Distribuição de Informação, Lda notificou um tratamento de dados pessoais com a finalidade criar uma base de dados de amostra para potenciais participantes em sondagens e inquéritos de opinião.
Os dados recolhidos são: Dados de identificação, Contactos, região, idade, instrução, profissão, rendimento do agregado familiar.
O fundamento de legitimidade é, nos termos do corpo do artigo 6° da LPD, o consentimento do titular dos dados.
Os dados recolhidos são pertinentes, adequados e não excessivos face à finalidade declarada (Cf. al. b) do art° 5° da Lei 67/98).
Assim, tendo em atenção o disposto nas disposições combinadas dos artigos 27°, e 30° da Lei n.º 67/98, de 26 de Outubro, regista-se o tratamento de dados pessoais nos seguintes termos:
Responsável pelo tratamento: Intercampus- Recolha, Tratamento e Distribuição de
Informação, Lda
Finalidade: criar uma base de dados de amostra para potenciais participantes em sondagens e inquéritos de opinião
Categoria de dados pessoais tratados: Dados de identificação, Contactos, região, idade, instrução, profissão, rendimento do agregado familiar
Formas de exercício do direito de acesso e rectificação: por contacto pessoal com o responsável.
Interconexões de tratamentos: Não há
Transferências de dados para países terceiros: Não há.
Prazo de conservação: os dados pessoais podem ser conservados pelo prazo máximo de 8 anos.

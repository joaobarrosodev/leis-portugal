# Registo da CNPD n.º 82/2008

COMISSÃO NACIONAL
DE PROTECÇAO DE DADOS
Proc.n. ° 1313 /'07
Registo n.° 02 108
Vianatece - Artesanato Tecelagem, Lda notificou um tratamento de dados pessoais com a finalidade de marketing.
Declara as seguintes categorias de dados pessoais: Nome, morada, telefone, e-mail, profissão, estado civil, habilitações literárias, data de nascimento.
Os dados são recolhidos directamente por impresso.
Os dados recolhidos são pertinentes, adequados e não excessivos face à finalidade declarada (Cf. al. b) do art° 5° da Lei 67/98).
O fundamento de legitimidade para o tratamento é, nos termos da alínea e) do artigo 6° da LPD, o consentimento do titular.
Assim, regista-se, nos termos dos artigos 27° n.º 1 e 30° n.º 1 da Lei n.º67/98, de 26 de Outubro, o tratamento, nos seguintes termos:
Responsável - Vianatece - Artesanato Tecelagem, Lda
Categoria de dados pessoais tratados - Nome, morada, telefone, e-mail, profissão, estado civil, habilitações literárias, data de nascimento
Finalidade - marketing.
Forma de exercício do direito de acesso e rectificação - Por solicitação escrita ao responsável.
Interconexões - Não há;
Comunicação de dados - Não há;
Fluxo transfronteiriço de dados - Não há.

COMISSAO NACIONAL
DE PROTECÇAO DE DADOS
Aos titulares dos dados deve ser garantido o direito de informação previsto no artigo 10°, bem como a possibilidade de o titular se opor à utilização dos seus dados para fins de marketing.

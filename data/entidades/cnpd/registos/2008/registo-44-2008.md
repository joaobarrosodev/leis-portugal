# Registo da CNPD n.º 44/2008

COMISSAO NACIONAL
DE PROTECÇÃO DE DADOS
Proc.n.° 575/07
Registo n.º 44 108
Media Capital - Editora Multimédia, SA notificou um tratamento de dados pessoais com a finalidade gestão de clientes e marketing.
Declaram as seguintes categorias de dados pessoais: dados identificação, dados de contacto e dados profissionais.
Os dados são recolhidos directamente por telefone ou na Internet.
É indicada a possibilidade de comunicação de dados às empresas do Grupo para fins de marketing.
Os dados recolhidos são pertinentes, adequados e não excessivos face à finalidade declarada (Cf. al. b) do art° 5° da Lei 67/98).
O fundamento de legitimidade para o tratamento é, nos termos do corpo do artigo 6° da LPD, o consentimento inequívoco do titular.
Assim, regista-se, nos termos dos artigos 27° n.º 1 e 30° n.º 1 da Lei n.°67/98, de 26 de Outubro, o tratamento, nos seguintes termos:
Responsável - Media Capital - Editora Multimédia, SA
Categoria de dados pessoais tratados - dados identificação, dados de contacto e dados profissionais.
Finalidade - gestão de clientes e marketing;
Forma de exercício do direito de acesso e rectificação - Por solicitação ao responsável.
Comunicação de dados - às empresas do Grupo
Interconexões - Não há;

COMISSÃO NACIONAL
DE PROTECÇÃO DE DADOS
Fluxo transfronteiriço de dados - Não há.
Aos titulares dos dados deve ser garantido o direito de informação previsto no artigo 10°. Relativamente à finalidade de marketing, deve o responsável, no momento da recolha, garantir ao titular a possibilidade de se opor à utilização dos seus dados para essa finalidade, nos termos da al. b do art° 12°, assim como a possibilidade de, autonomamente, se opor à comunicação de dados às empresas do Grupo.

# Registo da CNPD n.º 333/2008

COMISSÃO NACIONAL
DE PROTECÇÃO DE DADOS
Processo n.º 689/07
Registo n.333 /2008
A Intercampus- Recolha, Tratamento e Distribuição de Informação, Lda notificou um tratamento de dados pessoais com a finalidade criar uma base de dados de participantes em painéis.
Os dados recolhidos são: Dados de identificação, Contactos, região, idade, instrução, profissão, rendimento do agregado familiar, agregado familiar, passatempos, gostos pessoais e bens de consumo.
O fundamento de legitimidade é, nos termos do corpo do artigo 6° da LPD, o consentimento do titular dos dados.
Os dados recolhidos são pertinentes, adequados e não excessivos face à finalidade declarada (Cf. al. b) do art° 5° da Lei 67/98).
Assim, tendo em atenção o disposto nas disposições combinadas dos artigos 27°, e 30° da Lei n.º 67/98, de 26 de Outubro, regista-se o tratamento de dados pessoais nos seguintes termos:
Responsável pelo tratamento: Intercampus- Recolha, Tratamento e Distribuição de
Informação, Lda
Finalidade: base de dados de participantes em painéis.
Categoria de dados pessoais tratados: Dados de identificação, Contactos, região, idade, instrução, profissão, rendimento do agregado familiar, agregado familiar, passatempos, gostos pessoais e bens de consumo.
Formas de exercício do direito de acesso e rectificação: por contacto pessoal com o responsável.
Interconexões de tratamentos: Não há
Transferências de dados para países terceiros: Não há.
Prazo de conservação: os dados pessoais devem ser eliminados dos inquéritos 1 mês após validação.

# Registo da CNPD n.º 392/2008

COMISSAO NACIONAL
DE PROTECÇÃO DE DADOS
Processo n.º 1406/07
Registo n. ° 329 12008
A Motivação - Estudos Psico-Sociológicos, Lda notificou um tratamento de dados pessoais com a finalidade criar uma base de dados de amostra para participantes em sondagens e inquéritos de opinião
Os dados recolhidos são: Dados de identificação e Contactos.
O fundamento de legitimidade é, nos termos do corpo do artigo 6° da LPD, o consentimento do titular dos dados.
Os dados recolhidos são pertinentes, adequados e não excessivos face à finalidade declarada (Cf. al. b) do art° 5° da Lei 67/98).
Assim, tendo em atenção o disposto nas disposições combinadas dos artigos 27°, e 30° da Lei n.º 67/98, de 26 de Outubro, regista-se o tratamento de dados pessoais nos seguintes termos:
Responsável pelo tratamento: Intercampus- Recolha, Tratamento e Distribuição de
Informação, Lda
Finalidade: base de dados de amostra para participantes em sondagens e inquéritos de opinião.
Categoria de dados pessoais tratados: Dados de identificação e Contactos
Formas de exercício do direito de acesso e rectificação: por contacto pessoal com o responsável.
Interconexões de tratamentos: Não há
Transferências de dados para países terceiros: Não há.
Prazo de conservação: os dados pessoais podem ser conservados pelo prazo máximo de 10 anos.
Alerta-se o responsável que os futuros estudos a realizar, se forem identificados os titulares, constituem tratamentos de dados pessoais autónomos, pelo que nos termos do artigo 27° da LPD que carecem de notificação à CNPD de per si, devendo ser obtido o consentimento específico do titular.

COMISSÃO NACIONAL
DE PROTECÇÃO DE DADOS
Aos titulares dos dados deve ser garantido o direito de informação previsto no art.° 10° da LPD.
Lisboa, 3 de Outubro de 2008

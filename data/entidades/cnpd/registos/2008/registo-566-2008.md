# Registo da CNPD n.º 566/2008

COMISSÃO NACIONAL
DE PROTECÇÃO DE DADOS
Proc.n.° 744/08
Registo n.º 566/08
Danone Portugal, S.A. notificou um tratamento de dados pessoais com a finalidade de marketing.
Declaram as seguintes categorias de dados pessoais: Nome, apelido, data de nascimento, sexo, profissão, e-mail e password.
Os dados são recolhidos directamente pela Internet.
Declaram comunicação de dados à Waynext, Tecnologias de Informática, Lda.
Os dados recolhidos são pertinentes, adequados e não excessivos face à finalidade declarada (Cf. al. b) do art° 5° da Lei 67/98).
O fundamento de legitimidade para o tratamento é, nos termos da alínea e) do artigo 6° da LPD, o interesse do responsável.
Assim, regista-se, nos termos dos artigos 27° n.º 1 e 30° n.º 1 da Lei n.º67/98, de 26 de Outubro, o tratamento, nos seguintes termos:
Responsável - Danone Portugal, S.A., SA
Categoria de dados pessoais tratados - Nome, apelido, data de nascimento, sexo, profissão, e-mail e password.
Finalidade - Marketing;
Forma de exercício do direito de acesso e rectificação - Solicitação escrita ao responsável pelo tratamento
Interconexões - Não há;

COMISSÃO NACIONAL
DE PROTECÇÃO DE DADOS
Fluxo transfronteiriço de dados - Não há.
Conservação dos Dados - 10 anos
Comunicação de dados - Há comunicação de dados para Waynext,
Tecnologias de Informática, Lda.
Aos titulares dos dados deve ser garantido o direito de informação previsto no artigo 10° da Lei n.º 67/98, de 26 de Outubro, incluindo o n° 4, por haver recolha de dados por internet, bem como o direito de se oporem, de forma autónoma, à utilização dos seus dados para marketing da responsavel.

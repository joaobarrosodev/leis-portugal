# Registo da CNPD n.º 215/2013

D
COMISSÃO NACIONAL
DE PROTECÇAO DE DADOS
Processo n.° 1567/2011
REGISTO N.° 2/1' / 2013
A Oficina do Livro - Sociedade Editorial, Lda notificou à CNPD um tratamento de dados pessoais com a finalidade de gestão de utilizadores de site.
Os dados são recolhidos diretamente na
Internet http://www.oficinadolivro.leya.com.
Foi declarado recolherem os seguintes dados pessoais: Dados de identificação, dados de contacto, dados académicos, dados profissionais.
Os dados recolhidos são pertinentes e não excessivos face à finalidade declarada (Cf.
alínea b) do artigo 5.° da Lei n.° 67/98, de 26 de outubro - Lei de Proteção de Dados -
LPD).
Pretende-se conservar os dados por 5 anos, o que tendo em conta a finalidade do tratamento a CNPD considera excessivo, pelo que não deve ultrapassar 1 ano.
O fundamento de legitimidade para o tratamento é, nos termos do corpo do artigo 6°, o consentimento.
Assim, de acordo com as disposições conjugadas do n.º 1 do artigo 27.° e do n.º 1 do artigo 30.° da LPD, regista-se o tratamento nos seguintes termos:
Responsável
Finalidade
Oficina do Livro - Sociedade Editorial, Lda
Gestão de utilizadores de site.
Categoria de dados pessoais tratados
Dados de identificação, dados de contacto, dados académicos, dados profissionais.

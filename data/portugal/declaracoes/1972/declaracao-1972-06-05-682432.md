# Declaração

Segundo comunicação do Ministério dos Negócios Estrangeiros, Direcção-Geral dos Serviços Centrais, a [Portaria n.º 228/72](https://diariodarepublica.pt/dr/detalhe/portaria/228-1972-396955), publicada no Diário do Governo, 1.ª série, n.º 98, de 26 de Abril, saiu com a seguinte inexactidão, que assim se rectifica:

Onde se lê:

Consulados de 1.ª classe

...

Nogent-sur-Marne:

... Francos franceses

...

... 60100

deve ler-se:

Consulados de 1.ª classe

...

Nogent-sur-Marne:

... Francos franceses

...

... 60150

Onde se lê:

Consulados de 3.ª classe

...

Newark:

... Dólares americanos

...

... 2400

deve ler-se:

Consulados de 3.ª classe

...

Newark:

... Dólares americanos

...

... 2450

Secretaria-Geral da Presidência do Conselho, 22 de Maio de 1972. - O Secretário-Geral, Diogo de Paiva Brandão.

# Declaração de Rectificação n.º 1312/2011

Declaração de rectificação n.º 1312/2011

Por ter saído com inexactidão o despacho n.º 15948/2009, publicado no Diário da República, 2.ª série, n.º 133, 13 de Julho de 2009, relativo à licenciatura em Ciência Política, rectifica-se que, no anexo i, Plano de estudos, onde se lê:

«Análise de dados em Ciências Sociais: Descritiva/Descriptive Data Analysis For The Social Sciences - 55 (TP=54; OT=1)»

deve ler-se:

«Análise de dados em Ciências Sociais: Descritiva/Descriptive Data Analysis For The Social Sciences - 55 (TP=36; PL=18; OT=1)»

Onde se lê:

«Análise de dados em Ciências Sociais: Inferencial/Inferential Data Analysis For The Social Sciences - 55 (TP=54; OT=1)»

deve ler-se:

«Análise de dados em Ciências Sociais: Inferencial/Inferential Data Analysis For The Social Sciences - 55 (TP=36; PL=18; OT=1)»

Onde se lê:

«Análise de dados em ciências sociais: Multivariada/Multivariate data analysis for the social sciences - 55 (TP=54; OT=1)»

deve ler-se:

«Análise de dados em ciências sociais: Multivariada/Multivariate data analysis for the social sciences - 55 (TP=36; PL=18; OT=1)»

Onde se lê:

«Análise de dados em ciências sociais: modelos de dependência/Dependency models in data analysis for the social sciences - 55 (TP=54; OT=1)»

deve ler-se:

«Análise de dados em ciências sociais: modelos de dependência/Dependency models in data analysis for the social sciences - 55 (TP=36; PL=18; OT=1)»

Republicação do anexo i, Plano de estudos da licenciatura em Ciência Política

(Bachelor in Political Science)

[(ver documento original)](https://files.diariodarepublica.pt/2s/2011/08/162000000/3488934891.pdf)

26 de Julho de 2011. - O Reitor, Luís Antero Reto.

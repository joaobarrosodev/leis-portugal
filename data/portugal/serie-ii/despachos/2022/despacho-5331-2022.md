# Despacho n.º 5331/2022

Averbamento ao alvará n.º 14/2021

Averbamento n.º 1

Para os devidos efeitos, na presente data, procede-se aos seguintes averbamentos a este Alvará:

a) Nova denominação da empresa, que passa a ser "RCM PYROEVENTOS, Lda.", com o NIPC 516 839 705.

b) Adicionado à estrutura técnica responsável, Paulo Alexandre Santos da Costa, para o desempenho das funções de responsável técnico substituto.

c) As alterações ao quadro 1 do anexo:

1 - Produtos explosivos:

A) Fabricos autorizados:

Artifícios de divertimento/ fogos de artificio, n.º ONU 0333, classe 1, código classificação 1.1G, produção anual (kg) 15 000*.

Artifícios de divertimento/ fogos de artificio, n.º ONU 0335, classe 1, código classificação 1.3G, produção anual (kg), 20 000*.

Artifícios de divertimento/ fogos de artificio, n.º ONU 0336, classe 1, código classificação 1.4G, produção anual (kg) 20 000*.

Artifícios de divertimento/ fogos de artificio, n.º ONU 0337, classe 1, código classificação 1.4S, produção anual (kg) 5 000*.

* Valor estimado.

B) Armazenagem autorizada:

Objetos pirotécnicos para uso técnico**, n.º ONU 0066, classe 1, código classificação 1.4G.

Objetos pirotécnicos para uso técnico**, n.º ONU 0101, classe 1, código classificação 1.3G.

Artifícios de divertimento/fogos-de-artifício**, n.º ONU 0336, classe 1, código classificação 1.4G.

Objetos pirotécnicos para uso técnico**, n.º ONU 0428, classe 1, código classificação 1.1G.

Objetos pirotécnicos para uso técnico**, n.º ONU 0430, classe 1, código classificação 1.3G.

Objetos pirotécnicos para uso técnico**, n.º ONU 0431, classe 1, código classificação 1.4G.

Objetos pirotécnico para uso técnico**, n.º ONU 0432, classe 1, código classificação 1.4S.

** Produtos adquiridos para disponibilização do mercado.

Assim, no uso das competências subdelegadas pelo Exmo. Senhor Diretor Nacional, prevista no n.º 3.2 do Despacho n.º 1/GDN/2022, de 5 de janeiro, publicado no sítio institucional da PSP na internet, procedo à autenticação do presente Averbamento.

20 de abril de 2022. - O Diretor Nacional-Adjunto, Constantino José Mendes de Azevedo Ramos, superintendente-chefe.

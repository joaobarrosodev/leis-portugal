# REGULAMENTO DELEGADO (UE) 2024/2024 DA COMISSÃO

de 26 de julho de 2024

que completa o Regulamento (UE) 2020/1056 estabelecendo o conjunto comum de dados eFTI e os subconjuntos de dados eFTI

(Texto relevante para efeitos do EEE)

A COMISSÃO EUROPEIA,

Tendo em conta o Tratado sobre o Funcionamento da União Europeia,

Tendo em conta o Regulamento (UE) 2020/1056 do Parlamento Europeu e do Conselho, de 15 de julho de 2020, relativo a informações eletrónicas sobre o transporte de mercadorias [([^1])](http://publications.europa.eu/resource/cellar/d3bffea8-be9e-11ef-91ed-01aa75ed71a1.0020.03/DOC_1#ntr1-L_202402024PT.000101-E0001), nomeadamente o artigo 7.º,

Considerando o seguinte:

(1) O Regulamento (UE) 2020/1056 deve ser completado a fim de estabelecer o conjunto comum de dados eFTI e os subconjuntos de dados eFTI.

(2) O artigo 3.º, ponto 5), do Regulamento (UE) 2020/1056 especifica que cada subconjunto de dados eFTI deve incluir o conjunto estruturado de elementos de dados correspondente às informações regulamentares exigidas num ato jurídico específico da União ou do direito nacional. O artigo 3.º, ponto 6), do mesmo regulamento especifica que o conjunto comum de dados eFTI deve incluir o conjunto exaustivo de elementos de dados estruturados correspondentes a todos os subconjuntos de dados eFTI, no qual os elementos de dados comuns aos diferentes subconjuntos de dados eFTI são incluídos apenas uma vez. Além disso, o artigo 3.º, ponto 7), especifica que cada elemento de dados eFTI deve ter uma definição única e características técnicas precisas, tais como o formato, o comprimento e o tipo de letra.

(3) O objetivo do estabelecimento do conjunto comum de dados eFTI é simplificar o registo e o intercâmbio de dados em formato eletrónico, assegurando assim a disponibilidade de informações coerentes, para efeitos de verificação e comprovação da conformidade com a regulamentação do transporte. Os nomes, definições e formatos normalizados dos elementos de dados comuns aos diferentes subconjuntos de dados eFTI, incluindo, quando aplicável, listas de códigos harmonizadas e regras comerciais, permitirão aos operadores económicos registar os dados num formato claro e normalizado. Além disso, uma estrutura harmonizada para estes elementos de dados permitirá o intercâmbio automático desses dados entre as plataformas eFTI dos operadores e os sistemas informáticos das autoridades competentes.

(4) As informações sobre o transporte de mercadorias a registar e a trocar no quadro do ambiente eFTI são, na sua maioria, as mesmas informações que os operadores económicos têm de trocar no seu domínio de atividade, a fim de assegurar os fluxos operacionais, bem como para comprovar a sua conformidade com outros requisitos regulamentares fora do âmbito de aplicação do Regulamento (UE) 2020/1056. A fim de permitir a reutilização dos dados eFTI noutros intercâmbios e assegurar a interoperabilidade com os ambientes de intercâmbio eletrónico pertinentes entre empresas e entre empresas e autoridades, é importante alinhar a estrutura e a definição dos elementos de dados incluídos no conjunto comum de dados eFTI e nos subconjuntos de dados eFTI com os dos elementos de dados correspondentes que fazem parte dos três modelos de dados internacionais e da União mais relevantes: o modelo de dados do Código Aduaneiro da União (EU CDM) [([^2])](http://publications.europa.eu/resource/cellar/d3bffea8-be9e-11ef-91ed-01aa75ed71a1.0020.03/DOC_1#ntr2-L_202402024PT.000101-E0002), o modelo de dados do ambiente de plataforma única europeia para o setor marítimo (EMSWe) [([^3])](http://publications.europa.eu/resource/cellar/d3bffea8-be9e-11ef-91ed-01aa75ed71a1.0020.03/DOC_1#ntr3-L_202402024PT.000101-E0003) e o modelo de dados de referência sobre o transporte multimodal UN/CEFACT (MMT-RDM) [([^4])](http://publications.europa.eu/resource/cellar/d3bffea8-be9e-11ef-91ed-01aa75ed71a1.0020.03/DOC_1#ntr4-L_202402024PT.000101-E0004). Tal permitirá uma partilha e uma reutilização mais eficientes dos dados, reduzirá os encargos administrativos para os operadores económicos e melhorará a qualidade das informações sobre o trânsito de mercadorias a que as autoridades podem aceder para verificar a conformidade com a regulamentação aplicável.

(5) O artigo 83.º, n.º 4, do Regulamento (UE) 2024/1157 do Parlamento Europeu e do Conselho [([^5])](http://publications.europa.eu/resource/cellar/d3bffea8-be9e-11ef-91ed-01aa75ed71a1.0020.03/DOC_1#ntr5-L_202402024PT.000101-E0005) altera o artigo 7.º do Regulamento (UE) 2020/1056, a fim de fixar uma data posterior para a adoção das especificações do subconjunto de dados eFTI correspondente aos requisitos de informação relacionados com a circulação de resíduos abrangidos pelo âmbito de aplicação do Regulamento (UE) 2020/1056, tal como referido no artigo 2.º, n.º 1, alínea a), subalínea iv), desse regulamento. Por conseguinte, essas especificações não devem ser adotadas pelo presente regulamento delegado. A fim de permitir o alinhamento com as especificações conexas a adotar ao abrigo dos regulamentos de execução a que se refere o artigo 27.º, n.º 5, do Regulamento (UE) 2024/1157, essas especificações devem ser adotadas numa fase posterior e, o mais tardar, na data referida nesse artigo.

(6) A Comissão procedeu às consultas adequadas, inclusive ao nível dos peritos e junto das partes interessadas [([^6])](http://publications.europa.eu/resource/cellar/d3bffea8-be9e-11ef-91ed-01aa75ed71a1.0020.03/DOC_1#ntr6-L_202402024PT.000101-E0006),

ADOTOU O PRESENTE REGULAMENTO:

###### Artigo 1.º — Estabelecimento do conjunto comum de dados eFTI e dos subconjuntos de dados eFTI

O conjunto comum de dados eFTI e os subconjuntos de dados eFTI previstos no artigo 7.º do Regulamento (UE) 2020/1056 constam do anexo do presente regulamento.

###### Artigo 2.º — Entrada em vigor e aplicação

O presente regulamento entra em vigor no vigésimo dia seguinte ao da sua publicação no *Jornal Oficial da União Europeia*.

O presente regulamento é aplicável a partir da sua data de entrada em vigor.

O presente regulamento é obrigatório em todos os seus elementos e diretamente aplicável em todos os Estados-Membros.

Feito em Bruxelas, em 26 de julho de 2024.

***Pela Comissão***

***A Presidente***

**Ursula VON DER LEYEN**

# Regulamento (CEE) n.° 1045/88 do Conselho de 18 de Abril de 1988

**Regulamento (CEE) n.° 1045/88 do Conselho de 18 de Abril de 1988 que altera o Regulamento (CEE) n.° 2658/87 relativo à nomenclatura pautal e estatística e à pauta aduaneira comum** *Jornal Oficial nº L 103 de 22/04/1988 p. 0001 - 0002*

*****

REGULAMENTO (CEE) Nº 1045/88 DO CONSELHO

de 18 de Abril de 1988

que altera o Regulamento (CEE) nº 2658/87 relativo à nomenclatura pautal e estatística e à Pauta Aduaneira Comum

O CONSELHO DAS COMUNIDADES EUROPEIAS,

Tendo em conta o Tratado que institui a Comunidade Económica Europeia e, nomeadamente, o seu artigo 113º,

Tendo em conta a proposta da Comissão,

Considerando que o Regulamento (CEE) nº 2658/87 (1), alterado pelo Regulamento (CEE) nº 3985/87 (2), instituiu uma nomenclatura de mercadorias baseada no Sistema Harmonizado, a seguir designada « Nomenclatura Combinada », para satisfazer, simultaneamente, as exigências da Pauta Aduaneira Comum e das estatísticas do comércio externo da Comunidade, e fixou as taxas de direitos autónomos e convencionais da referida Pauta Aduaneira Comum;

Considerando que, aquando da transposição da Pauta Aduaneira Comum para o Sistema Harmonizado, a taxa do direito convencional aplicável aos produtos do código NC 8527 32 00 foi fixada tendo apenas em conta os rádios-despertadores que beneficiavam previamente da isenção desse direito convencional na subposição 85.15 A IIIb) 2 bb) 11 da Pauta Aduaneira Comum (3); que o código NC 8527 32 00 abrange, porém, igualmente sintonizadores e amplificadores-sintonizadores combinados com relógio, previamente sujeitos a um direito convencional com a taxa de 14 %, na subposição 85.15 A III b) 2 bb) 55 da Pauta Aduaneira Comum;

Considerando que, para rectificar esse erro, é, por conseguinte, conveniente alterar o Anexo I do Regulamento (CEE) nº 2658/87 para ter em conta aquela última taxa do referido direito,

ADOPTOU O PRESENTE REGULAMENTO:

###### Artigo 1º

1. No Anexo I do Regulamento (CEE) nº 2658/87, o código NC 8527 32 00 passa a ter a seguinte redacção:

1.2.3,4.5 // // // // // « Código NC // Designação das mercadorias // Taxas dos direitos // Unidade suplementar // 1.2.3.4.5 // // // autónomos (%) // convencionais (%) // // // // // // // 1 // 2 // 3 // 4 // 5 // // // // // // 8527 32 // Não combinados com um aparelho de gravação ou de reprodução de som, mas combinados com um relógio: // // // // 8527 32 10 // Rádios-despertadores // 22 // isenção // p/st // 8527 32 90 // Outros // 22 // 14 // p/st » // // 12. 1987, p. 1. (3) JO nº L 345 de 8. 12. 1986, p. 1.

2. As alterações introduzidas pelo presente regulamento aplicar-se-ão enquanto subposições da Taric até ao momento da sua introdução na Nomenclatura Combinada nas condições previstas no artigo 12º do Regulamento (CEE) nº 2658/87.

###### Artigo 2º

O presente regulamento entra em vigor no dia seguinte ao da sua publicação no Jornal Oficial das Comunidades Europeias.

O presente regulamento é obrigatório em todos os seus elementos e directamente aplicável em todos os Estados-membros.

Feito no Luxemburgo, em 18 de Abril de 1988.

Pelo Conselho

O Presidente

G. STOLTENBERG // // //

# Regulamento (CEE) nº 2294/89 da Comissão de 27 de Julho de 1989

**Regulamento (CEE) nº 2294/89 da Comissão de 27 de Julho de 1989 que altera o Regulamento (CEE) nº 1709/84 relativo aos preços mínimos a pagar aos produtores bem como aos montantes da ajuda à produção para certos produtos transformados à base de frutas e produtos hortícolas que podem beneficiar da ajuda** *Jornal Oficial nº L 218 de 28/07/1989 p. 0031 - 0032 Edição especial finlandesa: Capítulo 3 Fascículo 30 p. 0026 Edição especial sueca: Capítulo 3 Fascículo 30 p. 0026*

*****

REGULAMENTO (CEE) Nº 2294/89 DA COMISSÃO

de 27 de Julho de 1989

que altera o Regulamento (CEE) nº 1709/84 relativo aos preços mínimos a pagar aos produtores bem como aos montantes da ajuda à produção para certos produtos transformados à base de frutas e produtos hortícolas que podem beneficiar da ajuda

A COMISSÃO DAS COMUNIDADES EUROPEIAS,

Tendo em conta o Tratado que institui a Comunidade Económica Europeia,

Tendo em conta o Regulamento (CEE) nº 426/86 do Conselho, de 24 de Fevereiro de 1986, que estabelece a organização comum de mercado no sector dos produtos transformados à base de frutas e produtos hortícolas (1), com a última redacção que lhe foi dada pelo Regulamento (CEE) nº 1125/89 (2), e, nomeadamente, o nº 4 do seu artigo 6º,

Considerando que o Regulamento (CEE) nº 1709/84 da Comissão (3) estabelece, nomeadamente, a classificação dos figos secos em função das suas categorias e qualidades; que o preço mínimo a pagar ao produtor e a ajuda à produção são determinados com base em coeficientes aplicáveis em função das referidas classificações, que são fixados no anexo I do presente regulamento; que as disposições da parte A do anexo I devem ser alteradas de modo a ter em conta as qualidades de pastas de figo efectivamente transformadas;

Considerando que os anexos II e III do Regulamento (CEE) nº 1709/84 definem as qualidades que os figos secos devem apresentar após a transformação; que um dos critérios de diferenciação é o calibre dos frutos por quilograma; que a variedade de figos secos produzidos em Espanha e em Portugal são caracterizadas por frutos mais pequenos e, portanto, por um maior número de frutos por quilograma; que estes produtos são, pois, sempre classificados nas qualidades inferiores devido ao seu calibre, embora as suas características organolépticas, de apresentação e de limpeza correspondam a características das qualidades superiores; que convém alterar a classificação desses produtos de modo a ter em conta as suas características qualitativas reais e os hábitos de comercialização e de utilização; que convém alterar os anexos II e III do Regulamento (CEE) nº 1709/84 em consequência;

Considerando que as medidas previstas no presente regulamento estão em conformidade com o parecer do Comité de Gestão dos Produtos Transformados à base de Frutas e Produtos Hortícola,

ADOPTOU O PRESENTE REGULAMENTO:

###### Artigo 1º

O Regulamento (CEE) nº 1709/84 é alterado do seguinte modo:

1. O quadro constante da parte II do anexo I é substituído pelo quadro seguinte:

« Coeficientes aplicáveis à ajuda à produção

1.2,5.6 // // // // Qualidade/ Apresentação Categoria // Com peso líquido igual ou inferior a 1 quilograma // Outros 1.2.3.4.5.6 // // Rosário de figos e figos dispostos em filas sucessivas // "Round" "Piotoben" e "Lerida" // Figos a granel // Pastas de figo // // // // // // // // A // 1,3712 // 1,2536 // 1,20 // 1,2536 // 1,0186 // B // 1,2569 // 1,1492 // 1,10 // 1,1492 // 0,9337 // C // 1,1426 // 1,0447 // 1,00 // - // 0,8488 // D // 1,0284 // 1,9402 // 0,90 // - // 0,7639 » // // // // // //

2. Na letra A « Classificação e características » do anexo II, são introduzidas as seguintes alterações:

1. É suprimido o quarto travessão da alínea i).

2. É suprimido o quarto travessão da alínea ii).

3. É suprimido o quarto travessão da alínea iii).

4. Após a alínea iv), é aditado o seguinte texto:

« A a) Calibres

Em cada categoria, o calibre dos figos secos não transformados é determinado pelo número de frutos por quilograma, de acordo com o quadro seguinte:

1.2.3 // // // // Categoria // Variedades de fruto pequeno // Outras variedades // // // // A // até 74 // até 64 // B // de 75 até 84 // de 65 até 74 // C // de 85 até 110 // de 75 até 94 // D // mais de 110 // mais de 94 // // //

O calibre é avaliado a partir de uma amostra representativa do conjunto do lote, colhida aleatoriamente no mesmo. »

3. No final do anexo II, é aditada a letra D:

« D. Lista das variedades de figos de fruto pequeno

- Cuello de Dama

- Pajarito

- Granito

- Preto de Torres

- Pingo de mel, ou moscatel

- Cachopeira

- Cotio

- Branco do Douro

- Rei branco

- Rei preto. »

4. No annexo III, parte A « Normas de qualidade para figos secos », ponto II, letra A « Classificação »:

a) É suprimido o quinto travessão da alínea i);

b) É suprimido o quinto travessão da alínea ii);

c) É suprimido o quinto travessão da alínea iii);

d) É suprimido o terceiro travessão da alínea iv).

5. Na parte A do anexo III, o ponto III « Calibragem » passa a ter a seguinte redacção:

« III. Calibragem

A calibragem é determinada, para cada categoria, pelo número de frutos por quilograma, de acordo com o quadro seguinte:

1.2.3 // // // // Categoria // Variedades de fruto pequeno // Outras variedades // // // // A // até 72 // até 62 // B // de 73 até 82 // de 63 até 72 // C // de 83 até 95 // de 73 até 80 // D // de 96 até 110 // de 81 até 94 // // //

A calibragem é avaliada a partir de uma amostra representativa do conjunto do lote, colhida aleatoriamente no mesmo.

A lista das variedades de fruto pequeno consta da letra D do anexo II. »

###### Artigo 2º

O presente regulamento entra em vigor no terceiro dia seguinte à sua publicação no Jornal Oficial das Comunidades Europeias.

É aplicável a partir do início da campanha de comercialização de 1989/1990, em relação ao produto em causa.

O presente regulamento é obrigatório em todos os seus elementos e directamente aplicável em todos os Estados-membros.

Feito em Bruxelas, em 27 de Julho de 1989.

Pela Comissão
